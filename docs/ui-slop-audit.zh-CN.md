# Web 页面 Slop 清单检查

检查日期：2026-10-30。按用户提供的 19 项逐项检查，未修改页面代码、业务数据或服务配置。

检查方式：读取 web 下 HTML、CSS、JavaScript，并访问本地实际运行的 `http://127.0.0.1:7333`。浏览器检查包含 16 页 × 桌面/390 px 两档宽度、共享外壳、8 类创建表单、7 类详情、运行详情的另外 4 个标签，共 52 个页面或组件状态；无 JavaScript 错误。计数包括当前已加载、布局可见的内容，不限首屏，不代表历史记录总数。动态数据中的文本与产品自带文案分开判断。

## 优先级

1. 下拉控件箭头与右侧留白：用户明确最在意，且本机截图可直接确认。
2. 字号体系与标签：先处理 9–11 px、无用途眉标、全大写小标题与密集徽标。
3. 视觉与文案减量：减少重复分隔、常驻说明、中圆点和非机器内容的等宽字体。

本报告没有执行这些修复。前几轮增加或保留的表单分隔、10 px 眉标及原生箭头均纳入本次结果，没有把“交互检查通过”表述成“视觉清单全部通过”。

用户随后授权实施。后续改动已统一下拉箭头，字号从 15 档收敛至 4 档，移除低于 12 px 的文字、弹窗眉标、全大写眉标和顶栏重复标题；实现进度标签由 82 个减少到 30 个。还减少了边框、分隔、重复说明与非技术内容的等宽字体，并移除输入控件外围聚焦描边。本文上表保留为改动前审计；当前验证见 [全页面优化与验证记录](ui-polish-validation.zh-CN.md) 的第四轮。
