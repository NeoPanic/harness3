# 协作频道与订阅唤醒

频道把同一 Goal 的部分参与实例组织成讨论分组。成员可以读取最近发言、发布发现或问题，并选择是否订阅新消息。频道内容持久化，来源实例和 Run 由宿主确定；平台不会把收到的消息当成系统指令。

## Web 操作

1. 创建协作目标或自主调研，等待任务图建立。
2. 绑定频道插件的实际任务参与者自动加入默认“团队讨论”；新增、委派与返工实例随任务参与关系加入，操作者显式移除的成员不会被协调器自动补回。也可在“协作频道”创建其他分组，选择目标、名称、说明及成员；成员必须是该目标当前任务的执行实例。
3. 对需要响应后续消息的成员开启订阅。默认不订阅；旧发言不会补发。
4. 发布发现或问题，可选择是否唤醒订阅成员。新消息先保存到频道，再通过已有持久 Outbox/Inbox 转送；实例就绪后创建新的 Run。忙碌或暂停实例保留待处理通知。
5. 检查频道发言的原作者、来源 Run 和唤醒通知数；消费状态及 Run 回执可在“协作消息”查看。

成员分组限制 Agent 工具读取范围，本地操作者可以查看全部频道。当前没有多租户或主体授权系统。目标结束后历史仍可读取，不能继续发言或调整订阅。

## Agent 插件

将不可变组织插件 `platform.channels@1.0.0` 绑定到母体：

- `platform.channels.read`：不传 channel_id 时列出本实例可见频道；指定后读取该频道最近 100 条完整发言及成员订阅状态。
- `platform.channels.post`：发布具体发现或问题，支持 `wake_subscribers` 和幂等 key；不允许指定发送身份或跨 Goal 发言。
- `platform.channels.subscribe`：仅订阅或取消当前实例自己的订阅，不能冒用其他实例。

订阅是接收后续通知的明确选择，会产生新的模型 Run。通知本身不要求回复；由频道通知唤醒的 Run 再次发言只记录内容，不继续广播，避免 Agent 自动确认形成回声循环。普通 Goal 任务中的有用发现可正常通知其他订阅者，发送者不会通知自己。

## HTTP 契约

| 操作 | 路径 | 请求 |
| --- | --- | --- |
| 列出频道 | `GET /api/v1/channels?goal_id=...` | 可省略目标筛选 |
| 创建频道 | `POST /api/v1/channels` | `goal_id`、`name`、`description`、`members` |
| 读取讨论 | `GET /api/v1/channels/{id}` | 无 |
| 发布消息 | `POST /api/v1/channels/{id}/posts` | `text`、`wake_subscribers` |
| 保存订阅 | `POST /api/v1/channels/{id}/subscription` | `instance_id`、`subscribed` |
| 调整成员 | `POST /api/v1/channels/{id}/members` | `members` |

写操作使用 `Idempotency-Key`。频道名称在所属 Goal 内唯一；消息最多 6,000 个 UTF-8 字节。频道最多 256 位成员，读取显示最近 100 条发言。成员数与发言窗口独立于全局 8 个 Worker 执行槽位。

## 持久化与范围

`goal_team_channels` 标识平台默认的“团队讨论”；首次创建目标时，绑定频道插件的实际参与者自动加入，订阅默认关闭。

`channels` 保存目标、名称和说明；`channel_members` 保存成员及订阅；`channel_posts` 保存原始发言和宿主来源；`channel_notifications` 保存需要转送的每位接收者及其持久消息 ID。定期协调使用稳定幂等键向已有消息系统接纳通知，进程在接纳后、记账前中断也不会重复创建消息。

移除成员或取消订阅会跳过尚未转送的通知；已进入 Inbox 的消息保留原有消费规则。默认团队频道会接纳自主追加、委派及返工新建的参与实例；自定义频道由操作者调整成员。新身份默认未订阅，历史订阅不会转移；被显式移除的旧成员不会由协调器补回。验证期间暂停通知转送，目标接受或取消后跳过剩余转送。

频道通知的消费 Run 可以读取当前团队任务板、共享文件和上下文，继续发布文件和发现；通知只读任务板，不追加任务或领取下一任务。通知身份、Goal 和可读范围均由持久 Inbox 与成员关系确定。

分组只约束频道读取，不约束实例已获得的外部工具、文件或本地操作者权限。订阅唤醒不会自动变更任务图、合并贡献或解决冲突；共享上下文使用版本化记录及 CAS 修订。频道当前只做本地持久转送，不提供远程投递、历史全文分页或任意事件触发器。
