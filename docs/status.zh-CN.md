# 当前平台状态

Harness³ 的默认流程为共享任务板：发布工作后，控制面选择 Preset 并启动实例，Agent 原子认领、执行或拆分，再把子任务交回任务板。所有任务板 Agent 使用同一协议，实例生命周期由平台管理。已有 Goal、固定调研模板、频道、文件与验收流程继续保留。启动和模型配置见[使用指南](getting-started.zh-CN.md)，逐项能力及源码落点见[能力索引](capabilities.zh-CN.md)。

## 可用链路

- **共享任务板**：任务发布不绑定实例或 Preset。控制面按能力目录动态选型，实例启动后认领；拆分来源成功后激活子任务，子任务完成后原任务重新可认领以整合结果。选型模型可独立配置，任务、实例和 Run 保留来源。当前提供 Web、HTTP 与 CLI。
- **Goal 内自主协作**：兼容流程支持候选池内请求下一任务、按母体追加任务或授权委派。来源 Run 成功后激活请求；未派发的直接下游等待新增贡献。这套候选池协议与新任务板分开。
- **协作空间**：同 Goal 的成员通过频道讨论、持久消息交接及版本化共享上下文交换发现。频道插件参与者自动进入团队讨论，订阅默认关闭；开启订阅后，新发言可唤醒成员，通知 Run 的回复不继续广播。
- **文件与验收**：实例读写自己的 UTF-8 文件，发布不可变文件/JSON 快照供同 Goal 成员读取。验证器检查冻结证据，可按失败产物定位局部返工任务及其下游；人工验收保留最终决定。
- **能力扩展**：提示词包与本地进程工具支持在线安装、固定版本绑定和健康检查。提供[文本统计](../examples/plugins/text-inspector/)、[HTTP 读取](../examples/plugins/http-reader/)和[工作区母体](../examples/plugins/workspace-preset/)示例。

新任务板 Demo 验证根任务拆分为两项子任务、执行和重新认领整合；内容为确定性演示。固定调研模板的离线体验选择 `demo-team@1.0.0`，真实 Responses 调研可选择 `research-team@1.1.0`，该模板另行提供频道、文件 / JSON 和共享上下文工具。

任务板尚未自动接入 Goal 的频道、文件产物、独立验证与人工验收。任务 `completed` 表示已知 Run 执行成功，不构成验收标准已经独立验证的证明。

## 运行边界

平台采用单 daemon、SQLite、本地 Worker 和受信任插件。进程插件以 daemon 所在系统用户权限执行；文件工具限制相对路径和符号链接，但没有 OS 沙箱、多租户授权或多机租约。团队费用没有硬上限，Run 仍受轮次、工具调用次数和超时约束。模型接入提供 OpenAI-compatible Chat Completions、OpenAI Responses、Anthropic Messages 三类非流式协议。

| 本地容量约束 | 默认值 |
| --- | --- |
| 活跃实例及待创建预留 | 256 |
| Worker 槽 | 8；同一实例串行 |
| 每 Goal 任务及待追加/待委派预留 | 64 |
| 委派深度 / 单次子任务 / 每根后代 | 6 / 8 / 48 |

Goal 内追加不删除或改写已运行节点，其接续领取要求实例已在候选池。新任务板通过任务范围、实例能力与事务认领约束执行者，发布者无需提供候选实例。频道不自动裁决事实冲突；文件证据及 HTTP 回执不能证明外部结论正确。任意任务图重写、通用自主修复、流式模型、远程插件 loader、分布式 Worker、预算治理、细粒度授权和执行隔离尚未提供。容量值属于输入和调度限制，不构成吞吐性能保证。

## 验证范围

已验证原生 Cargo check、Clippy、Rust 测试、rustdoc、quickstart、HTTP 插件 fixture，以及桌面 Web 的主要操作链路。确定性 Demo 和真实 OpenAI Responses / `gpt-6-luna` 均验证了多实例协作、文件交接与验证；真实模型还验证了自主追加、依赖调整和后续汇总。浏览器覆盖 1024、1440、1920 px；完整屏幕阅读器、跨浏览器、多机故障及单/多 Agent 效果对照尚未完成。

能力契约见[共享任务板](task-board.zh-CN.md)、[Goal 内自主性](autonomy.zh-CN.md)、[频道](channels.zh-CN.md)、[工作区](workspaces.zh-CN.md)和[验证](verification.zh-CN.md)。目标架构及扩展边界见[架构设计](managed-agents.zh-CN.md)。
