# Harness³ brand

Harness³ is a composable harness platform for agent collectives. The repository includes a Rust runtime core and a local Managed Agents control plane. The brand connects the generative meaning of 三 in Chinese philosophy with multiplication through composition.

> 道生一，一生二，二生三，三生万物。——《道德经》第四十二章

The cube expresses harness × harness × harness, extensible to N cooperating execution units. It represents a direction for composition, not a promise of unbounded runtime capacity.

![Harness³ banner](banner.svg)

Three open isometric frames assemble into a cube. Each frame is a unit; their shared geometry conveys composition. The three faces reference 三, while the cube carries the mathematical reading. All SVGs are static, have accessible titles and descriptions, and use no scripts, remote resources, or embedded raster images. The standalone marks use geometry only; the banner wordmark uses system fonts.

Keep at least one sixth of the mark's width as clear space. Use the standalone mark at 32 px wide or larger; use the banner at 720 px wide or larger so its descriptor remains readable. Preserve the viewBox and aspect ratio. Do not rotate, stretch, rearrange faces, or place the colored mark on a visually busy surface. Use nearby text or appropriate alt text to identify Harness³.
