# 协作产物、评审与返工 v1

协作任务完成后，控制面把原始文本保存为不可变 Artifact。每份产物绑定 Goal、任务 key、当前轮次、来源 Run 和实例身份，并记录 UTF-8 字节数和 SHA-256 摘要。版本号等于任务的协作轮次；本版每项任务每轮只有一份文本产物。失败、取消、未知工具效果不会被发布为成功贡献。

## 贡献与验收

下游任务接收上游文本、Run ID、产物 ID、版本、摘要和检查结果。文本始终作为不受信任的证据传递，不能扩大下游工具权限。私有会话不会广播；共同目标、验收标准和显式依赖继续来自宿主。

平台在发布时记录两项确定性检查：文本包含非空白内容，文本不超过 1 MiB。失败内容仍原样保存，便于诊断；检查不判断事实、引用或研究质量，不替代评审，也不阻止下游读取已完成 Run 的贡献。最终验收要求全部当轮产物存在且通过两项检查，并重新校验内容摘要。

`awaiting-review` 表示执行完成、等待评审。人工验收必须提交说明和 `expected_round`；控制面在同一事务内固定当轮所有任务的产物 ID / 摘要清单，并结算 Goal。旧页面提交其他轮次的验收会返回冲突。未传轮次的旧客户端仅能验收第一轮。

## 返工

目标处于待验收时，可以提交修改意见，最多 3 轮（初始执行加两次返工）：

1. 校验当前轮次、输入、实例配额与调研并发配额，保留旧轮次的任务身份、Run、评审意见和所有产物。
2. 默认按每项任务原来的固定母体及实例参数，预留一份 finite 实例组；每个任务获得新身份、新会话。全部预留与轮次变更原子提交，容量不足会整体回滚。
3. 实例由既有分批协调器异步创建，整张依赖图重新执行。每项任务收到本轮修改意见和自己的上一版文本；下游继续等待本轮的上游贡献，不混用旧轮次输出。
4. 当轮待验收、失败或取消时回收平台为返工创建的实例组。取消在实例尚未创建时也释放预留，历史记录保留。

自主调研保留最初的分工计划、规划 Run 与同一个 Goal；返工只创建新的研究者和汇总实例，不重新规划。新团队加入调研成员历史，保留初始规划者的谱系引用。调研每轮重新获得 15 分钟期限，返工实例 TTL 为 30 分钟。

API 还允许显式 Goal 提供完整 `assignments`（任务 key 与现有就绪实例）。这种模式由调用者管理实例生命周期，会保留实例既有会话；自主调研使用默认新团队模式。Web 始终使用新团队。

返工是用户明确要求的再次执行，会重复工具调用和模型费用；当前不自动判定工具副作用是否适合重复。失败或未知结果不能从这个入口重试，须先调查原始回执。返工不撤销原来的外部效果。

## 四入口

| 操作 | HTTP | CLI | MCP | Web |
|---|---|---|---|---|
| 产物目录 | `GET /api/v1/artifacts?goal_id=ID&after=0&limit=50` | `artifacts list --goal-id ID` | `artifacts_list` | 协作产物 |
| 产物与原文 | `GET /api/v1/artifacts/{id}` | `artifacts show ID` | `artifacts_show` | 预览 / 下载 / 来源 Run |
| 返工 | `POST /api/v1/goals/{id}/rework` | `goals rework ID --file rework.json --key KEY` | `goals_rework` | 要求修改 |
| 验收 | `POST /api/v1/goals/{id}/accept` | `goals accept ID --review TEXT --expected-round 2` | `goals_accept` | 验收本轮产物 |

返工 body 示例：

```json
{"expected_round":1,"note":"补充争议点的证据，并明确未核实结论。"}
```

写入口共享本地认证。返工必须携带 `Idempotency-Key`；同键同内容重复返回原接纳回执，改变内容返回冲突。客户端超时后应复用原键与原内容。产物目录按升序游标查询，每页最多 100 项；Web 目录展示最近 100 项，目标详情保留所有轮次。

本地 schema v8 增加产物、轮次和返工容量分配，旧成功贡献在打开数据库时补建，保留原始 Run 完成时间。旧版人工验收记录保留，不补造当时不存在的产物验收清单。产物当前存于 SQLite，尚无文件/二进制 Artifact、外部 blob store、结构化证据 schema、专用验证 Agent、自动返工、局部重跑或未知结果处置后的安全重试协议。
